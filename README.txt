TRUEHAVEN KITCHEN & BATH: WEBSITE DRAFT (LAYOUT A)
====================================================

WHAT'S INSIDE
  25 pages (.html)    All pages from the approved Website Pages doc
  assets/style.css    Shared styles (brand colors, fonts, animations)
  assets/main.js      Shared scripts (menu, animations, sliders, lightbox, form)
  images/             28 project photos pulled from the Drive (old-site screenshots)
  brand/              Truehaven logo and icon SVGs from the Drive
  sitemap.xml         For Google Search Console
  robots.txt          Points search engines to the sitemap

UPLOAD TO HOSTINGER
  1. hPanel > File Manager > public_html
  2. Upload the CONTENTS of this folder (not the folder itself)
  3. index.html must sit directly inside public_html

UPLOAD TO GITHUB
  1. Create a repo and upload the contents of this folder to the root
  2. Optional preview: Settings > Pages > Deploy from branch > main / root
